# 유사 앱 참고 조사

조사일: 2026-10-27. 공식 제품 소개, 도움말, 변경 내역 및 개발자 배포 설명을 기준으로 조사했습니다. 앱을 설치해 직접 비교한 결과가 아니며 조작감·안정성·성능·사용자 만족도는 검증하지 않았습니다. 플랫폼·요금제별 차이가 있으므로 전체 제품 기능과 모바일 기능을 구분했습니다. 가격 및 이용자 수의 비교는 이번 범위에 포함하지 않았습니다.

## 결론과 제품 방향 — 분석 의견

로어 위버가 우선 참고할 대상은 모바일 창작 관리 흐름의 Fortelling, 시각 편집의 Obsidian Canvas, 계층·지도 탐색의 World Anvil입니다. Campfire는 창작 도구 구성, Fantasia Archive는 오프라인 자료 연결의 참고 대상입니다.

‘한국어 기본 지원, 로그인 불필요, 모바일에서도 편집 가능한 관계도, 이미지까지 기기에 저장하고 복원’의 조합을 제품 방향으로 삼을 수 있습니다. 경쟁 제품 전체를 조사한 것은 아니므로 유일한 앱이거나 시장 수요가 검증됐다는 뜻은 아닙니다.

## 1. Fortelling — 가장 직접적인 비교 대상

공식 자료에서 확인한 기능:
- 인물·장소·아이템·종족 등을 공통 이야기 요소로 관리하고 서로 연결.
- 대표 이미지, 추가 이미지, 속성, 메모, 라벨, 사용자 정의 필드.
- 관계 보드에서 이야기 요소를 이름 있는 화살표로 연결하고 장·서사별 보드 구성.
- 연표에서 사건에 인물·장소를 연결.
- 2026-06-17의 5.0 변경 내역에는 가계도와 보드 주석 기능 추가가 기록됨.
- 공식 FAQ는 온라인 중심이라고 설명하며 자료 CRUD와 모바일 원고 작성 등 일부 기능만 오프라인 지원. 프로젝트 생성·협업 등은 온라인 필요.

우리 앱에 적용할 제안:
- 대표 이미지와 자료 갤러리를 구분.
- 긴 인물 폼을 기본 정보·성격·서사·메모로 접고 펼치며 빈 속성은 상세에서 숨김.
- 하나의 전체 관계도에서 나아가 ‘주인공 주변’, ‘왕실’, ‘1부 등장인물’처럼 여러 보드를 저장.
- 인물·세력·장소·사건을 유형별 관계 섹션으로 분류해 보여줌.

출처: [이야기 요소](https://wiki.fortelling.app/story-elements/story-elements), [보드·연표 튜토리얼](https://wiki.fortelling.app/interactive-tutorials), [FAQ](https://wiki.fortelling.app/frequently-asked-questions), [변경 내역](https://www.fortelling.app/changelog).

## 2. Campfire — 폭넓은 창작 도구 구성

공식 자료에서 확인한 기능:
- 인물, 지역, 설정, 지도, 연표 등 모듈로 창작 자료를 관리.
- Relationships 모듈은 자유로운 흐름도 기반 관계망·가계도를 지원.
- 데스크톱 앱은 오프라인 작업을 지원하지만 CF Creators 모바일 앱은 인터넷 연결 필요.
- 공식 FAQ 기준 모바일 앱에는 Relationships 모듈이 포함되지 않음. 데스크톱 기능을 모바일 지원 기능으로 간주하면 안 됨.

우리 앱에 적용할 제안:
- 세계관을 처음부터 광범위한 입력 양식으로 채우게 하기보다 필요한 유형만 바로 등록하게 함.
- 작품 한 개 안에 목적별 관계도를 둘 수 있게 함.
- 모바일 관계도에서 상세 화면을 왕복하지 않고 인물 생성·관계 편집을 끝낼 수 있게 함.

출처: [제품 모듈 소개](https://campfirewriting.com/write), [플랫폼별 지원](https://www.campfirewriting.com/apps), [관계도 소개](https://www.campfirewriting.com/learn/relationships-tutorial), [모바일 FAQ](https://www.campfirewriting.com/faq).

## 3. World Anvil — 구조화된 세계관과 지도·가계도

공식 자료에서 확인한 기능:
- 세계관 문서와 상호 연결, 가계도, 조직도, 가상 달력, 연표 등 제공.
- 부모·배우자·자녀를 지정해 가계도를 구성하며, 문서 연결 또는 새 인물 생성을 같은 흐름에서 수행.
- 사용자 지도 이미지에 마커·레이어를 두고 자료나 다른 지도로 연결.
- 공식 FAQ 기준 브라우저 기반이며 오프라인 사용은 지원하지 않음.

우리 앱에 적용할 제안:
- ‘부모→자녀’, ‘상위→하위 조직’은 자유 관계도와 별도로 계층에 맞는 자동 배치를 제공.
- 세계→국가→도시→건물로 이동하는 지역 트리와 경로 표시.
- 지도 마커에 새 장소 등록·기존 장소 연결·마커 이동을 함께 제공.
- 복잡한 세계관 기능은 단계적으로 노출해 모바일 첫 화면을 단순하게 유지.

출처: [제품 FAQ](https://www.worldanvil.com/faq), [가계도 가이드](https://www.worldanvil.com/learn/family-trees/family-trees-guide), [지도 가이드](https://www.worldanvil.com/learn/map-making/maps).

## 4. Obsidian — 관계 탐색과 시각 편집의 참고 대상

소설 전용 앱은 아닙니다. 아래 두 기능은 서로 구분해야 합니다.
- Graph View: 문서의 링크를 시각화하며 현재 문서 주변 연결을 깊이별로 탐색할 수 있음.
- Canvas: 문서·미디어를 카드로 배치하고 연결·그룹화하는 시각 편집 공간. 모바일의 길게 누르기, 확대·이동, 실행 취소·다시 실행을 문서화하고 있음.
- Canvas 데이터는 로컬의 공개 JSON Canvas 형식으로 저장. 공식 도움말 기준 PNG 내보내기는 데스크톱에서 지원하며 모바일에서는 지원하지 않음.

우리 앱에 적용할 제안:
- 자료 하나를 중심으로 1단계·2단계 연결을 선택해 표시.
- 노드 이동과 관계 삭제의 실행 취소·다시 실행.
- 여러 노드 선택·정렬·그룹 이동, 격자·노드 맞춤.
- 보기 모드와 편집 모드를 나눠 의도하지 않은 이동을 줄임.
- 독립된 텍스트 내보내기도 제공해 전용 앱 없이 자료 내용을 읽을 수 있게 함.

출처: [Graph View](https://obsidian.md/help/plugins/graph), [Canvas 제품 소개](https://obsidian.md/canvas), [Canvas 도움말](https://obsidian.md/help/plugins/canvas).

## 5. Fantasia Archive — 오프라인 세계관 데이터 관리

공식 사이트는 컴퓨터에서 사용하는 무료 오프라인 세계관 도구로 설명합니다. 개발자 배포 설명에는 양방향 관계 자동 반영, 문서 유형별 필드, 태그, 계층 구조, 검색, 오프라인 프로젝트 가져오기·내보내기가 제시되어 있습니다. 배포 설명의 일부는 오래된 안내이므로 현재 세부 UI나 모바일 지원으로 확대 해석하지 않았습니다.

우리 앱에 적용할 제안:
- 소속·참여·상위 지역을 단순한 관계 이름에만 의존하지 않고 자료 유형에 맞게 등록.
- 한쪽에서 추가한 관계는 양쪽에서 일관되게 표현.
- 깊은 계층 탐색과 휴대 가능한 전체 백업을 기본 흐름으로 제공.

출처: [공식 사이트](https://fantasiaarchive.com/), [개발자 배포 설명](https://cartographyassets.com/assets/10089/fantasia-archive/).

## 현재 앱의 격차와 제안 우선순위 — 개발 판단

| 우선 | 개선 | 현재와 달라지는 사용자 경험 |
|---|---|---|
| 1 | 관계도에서 바로 관계 편집 | 선 선택→관계 수정·삭제를 같은 화면에서 완료 |
| 1 | 실행 취소·다시 실행 | 실수로 이동하거나 삭제한 편집을 되돌림 |
| 1 | 유형별 관계 관리 | 소속 세력·참여 사건·관련 장소가 상세에서 따로 표시됨 |
| 1 | 휴지통·복원과 복원 전 미리보기 | 삭제 자료를 되살리고 백업의 작품·자료 수를 확인한 뒤 처리 |
| 2 | 여러 관계 보드 | 전체·왕실·주인공 주변 등을 별도로 구성하고 저장 |
| 2 | 의미에 맞는 자동 배치 | 가계도·조직도는 계층 배치, 일반 관계는 군집 배치 |
| 2 | 실제 태그·카테고리 관리 | 같은 태그를 선택·일괄 변경하고 중복 표기를 줄임 |
| 2 | 지역·조직 트리 | 상하위 구조와 현재 위치를 빠르게 파악 |
| 2 | 관계 중심 탐색 | 주변 1·2단계, 관계 종류·세력·태그로 필요한 연결만 표시 |
| 3 | 지도 편집 확대 | 여러 지도 선택, 마커 이동, 국가→도시 지도 이동 |
| 3 | 관계 변화 이력 | 작품 시점별 동맹·적대·소속 변화 표현 |
| 3 | 문서형 내보내기 | ZIP 복원 외에 사람에게 읽히는 설정집 생성 |

우선순위는 공식 제품의 등급이나 시장 통계가 아니라 현재 로어 위버 구현과 핵심 목표를 바탕으로 한 제안입니다. 휴지통·복원 미리보기 등은 이번 조사에서 모든 경쟁 제품에 공통으로 확인된 기능이라는 뜻이 아닙니다.

이번 단계에서는 조사 문서만 추가했으며 앱 기능은 변경하지 않았습니다.
