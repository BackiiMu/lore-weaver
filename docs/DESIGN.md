# 디자인 적용 기록

참고: 사용자가 제공한 `DESIGN-notion.md` (Notion 디자인 언어 분석).

문서를 앱의 시각적 참고 자료로 사용했습니다. 마케팅 사이트의 로그인·요금제·히어로 섹션은 앱 기능에 추가하지 않았습니다.

- 배경: 따뜻한 종이색 `#f6f5f4`, 카드·입력면: 흰색
- 글자: 따뜻한 검정 `#31302e`, 보조 글자 `#615d59`
- 동작·선택 강조: 파란색 `#0075de`
- 경계: `#e6e6e6` 얇은 선과 최소한의 그림자
- 제목: 26~32px, 굵기 700; 본문: 15~16px, 편안한 줄 간격
- 형태: 입력창 4px, 유틸리티 버튼 8px, 카드 12px, 대화상자 16px
- 작은 색상 아이콘은 인물·관계도·세계관 분류에 사용
- 작품 서재: 제목·설명·검색의 문서형 계층, 첫 작품 생성 빈 화면
- 넓은 화면: 서재 본문 최대 너비 1080px
- 밝은 테마·어두운 테마 공통 적용, 관계도 표면과 선택 상태도 테마에 연동

전용 NotionInter 폰트를 포함하지 않습니다. 네트워크 없이 기기 기본 한글·시스템 폰트를 사용합니다. 참고 자료의 54~64px 마케팅 헤드라인은 모바일 앱에 맞게 줄였습니다.

공통 스타일: `lib/app/theme.dart`.
