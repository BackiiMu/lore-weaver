# 관계도·연결 탐색 개선

2026-10-27, 유사 앱 조사 뒤 제안한 여섯 개선 영역을 구현했습니다.

## 관계도에서 편집과 되돌리기

- 관계선을 누르면 수정·삭제 메뉴가 열립니다. 겹치는 평행 관계는 그리는 경로와 같은 경로로 선택을 판정합니다.
- 상단 실행 취소·다시 실행은 노드 이동, 자동 배치, 보드에 노드 추가·제거, 관계 추가·수정·삭제를 되돌립니다.
- 현재 보드 편집 세션의 최근 50개 작업을 보관합니다. 보드 전환이나 화면 종료 뒤의 이력은 유지하지 않습니다. 인물 자체의 생성·삭제와 보드 생성·삭제는 이 이력의 대상이 아닙니다.
- 다른 화면에서 해당 좌표나 관계를 수정했다면 이전 내용으로 덮어쓰지 않고 안내합니다.
- 관계도 메뉴의 보기 모드는 이동·관계 편집을 막고 화면 이동·확대·자료 열기를 허용합니다.

## 목적별 관계 보드

관계도 메뉴 → **현재 보기를 새 보드로 저장**에서 이름을 입력합니다. 중심 필터로 보이는 인물만 별도 보드로 저장할 수도 있습니다. 상단 보드 선택에서 전체·왕실·1부 등장인물 등으로 전환합니다.

- 인물 구성과 배치는 보드마다 별도로 저장합니다.
- 인물 정보와 관계는 작품 전체에서 공유합니다. 어느 보드에서 관계를 수정해도 같은 관계의 내용은 모든 보드에서 바뀝니다.
- + 메뉴로 기존 인물을 추가하거나 새 인물을 등록합니다.
- 캔버스 제거는 인물 삭제가 아닙니다. 다른 보드나 상세 자료는 유지합니다.
- 보드 이름 변경·삭제는 관계도 메뉴에서 수행합니다.
- 작품 복제와 ZIP 백업은 보드·노드 구성을 포함합니다.

## 의미에 맞는 배치와 주변 탐색

관계도 메뉴에서 격자, 가계도·조직도, 관계별 묶음 배치를 선택합니다.

- 가계도·조직도 배치는 부모·자녀, 상위·하위 조직/지역, 스승·제자 관계를 해석해 상위 항목을 위에 놓습니다.
- 관계별 묶음 배치는 서로 연결된 구성요소별로 묶고 격자 배치합니다. 힘 기반 물리 배치가 아닙니다.
- 중심 자료 주변 1단계·2단계와 관계 이름 필터를 제공합니다.
- 임의의 가족·소속 표현을 자동 추론하거나 모든 선 교차를 제거하지는 않습니다. 정해진 관계 이름을 사용해야 계층으로 해석됩니다.

## 유형별 연결·계층 탐색

자료 상세에 관련 인물, 소속·관련 세력, 관련 장소, 참여·관련 사건, 관련 설정을 구분합니다. 각 섹션에서 같은 유형의 자료를 선택해 연결할 수 있습니다. 인물→세력은 소속/구성원, 인물→사건은 참여 사건/참여자 같은 기본 관계 이름을 제공합니다.

작품 메뉴의 **지역 계층 / 조직 계층**은 상위·하위 연결을 접고 펼치는 트리로 표시합니다. 같은 자료가 여러 경로에 있으면 다시 펼치지 않고 상세 이동으로 연결합니다. 계층 연결 추가·변경은 자료 상세의 연결 편집에서 수행합니다.

## 태그·카테고리 관리

작품 메뉴의 **태그·카테고리 관리**에서 항목을 등록하고 사용 자료 수를 확인합니다. 이름 변경·병합과 표시 제거는 같은 작품의 저장 자료와 초안에 일괄 반영됩니다. 제거는 자료 삭제가 아닙니다.

편집 폼의 태그·카테고리 아래 선택 버튼으로 기존 항목을 고릅니다. 태그는 쉼표로 구분하며 중복과 앞쪽 #을 정리합니다. 설정 자료 목록에서는 카테고리별로 필터링합니다. 선택 화면에 기본 설정 카테고리 제안을 제공하지만 사용 전 더미 자료를 생성하지 않습니다.

## 휴지통과 복원 미리보기

작품·자료의 삭제 버튼은 휴지통으로 옮깁니다. 작품 메뉴 또는 설정에서 휴지통을 열어 복원·영구 삭제합니다.

- 자료 복원은 연결·첨부·기존 배치·지도 마커·초안을 함께 복구합니다.
- 연결 대상이나 소속 작품·보드가 삭제되어 있으면 먼저 복원해야 합니다. 필요한 참조가 없거나 ID가 겹치면 전체 복구를 취소하고 휴지통 항목을 남깁니다.
- 첨부 정리는 휴지통이 참조하는 파일도 보존합니다. 영구 삭제 후 참조가 없어진 파일은 정리 대상이 됩니다.
- 휴지통 자료와 첨부파일도 백업에 포함합니다.
- ZIP 가져오기는 검증 후 작품 제목·자료·관계·파일·휴지통 수와 기존 데이터 충돌 건수를 표시합니다. 충돌이 있으면 복원 버튼을 비활성화합니다.

추가 의존성은 없습니다. 새 데이터·배치 테스트는 `test/improvements_test.dart`, 새 화면 테스트는 `test/improvements_ui_test.dart`에 있습니다.

- `flutter analyze`: 지적 없음.
- `flutter test`: **44개 통과**. 기존 22개 + 데이터·배치 14개 + 새 화면 8개.
- `flutter build ios --simulator --no-codesign`: 최신 소스 빌드 성공.

- 실제 기기에서의 파일 선택·공유·백업 종단 검증과 스토어 배포 검증은 여전히 남아 있습니다.


## 인물 연속 등록 표시 오류 수정

관계도에서 ‘이름’ 다음 ‘와’를 등록하면 두 번째 노드가 휴대폰 화면 오른쪽 밖에 생기는 문제를 재현해 수정했습니다. 개별 보드에서는 신규 노드가 모두 같은 좌표에 생성되는 문제도 함께 수정했습니다.

- 관계도를 열거나 노드가 추가될 때 실제 캔버스 영역에 맞춰 화면을 조정합니다. 저장된 서로 다른 좌표는 바꾸지 않습니다.
- 신규·다시 추가한 노드는 다른 노드와 겹치지 않는 위치를 찾아 저장합니다. 새 인물이 중심 필터에 가려지지 않도록 필터를 해제합니다.
- 이전 버전에서 정확히 같은 좌표에 저장된 노드는 보드를 처음 열 때 분리합니다. 일반적인 수동 배치의 일부 겹침은 변경하지 않습니다.
- ‘이름’→‘와’ 실제 연속 등록, 기존 좌표 유지·화면 맞춤, 개별 보드의 연속 등록, 기존 중첩 좌표 복구를 390px 화면에서 검증했습니다.
- 정적 분석 지적 없음, 전체 테스트 48개 통과.
